## 6. Security, Content Security Policy & DOM Safety Audit

### 6.1. Content Security Policy (CSP) & Zero Inline Scripts
- **Firefox MV2 Requirement:** Mozilla AMO Review Guidelines strictly prohibit inline `<script>` tags on extension pages (`script-src 'self'`).
- **Audit Result:**
  - `entrypoints/newtab/index.html` contains **0 inline script blocks**.
  - The anti-flash theme script was extracted to `entrypoints/newtab/anti-flash.ts` and imported in `main.tsx`, bundled cleanly as an external module chunk (`chunks/anti-flash-*.js`).
  - Zero CSP violations reported in Gecko or Chromium developer consoles.

### 6.2. DOM Safety & AST-Based Rendering
- **Prohibition of Dynamic Code Execution:** 0 occurrences of `eval()`, `Function()`, or `new Function()`.
- **Prohibition of Raw HTML Execution:** 0 occurrences of `dangerouslySetInnerHTML` in the user-facing application.
- **Markdown Rendering:** `src/features/notes/components/MarkdownRenderer.tsx` uses a custom recursive AST parser producing native React DOM elements (`<h3>`, `<p>`, `<code>`, `<ul>`, `<li>`, `<table>`).
- **URL Protocol Allowlisting:** URLs in bookmarks, notes, and resources are validated with `isSafeBookmarkUrl` (`src/utils/bookmarkSecurity.ts`), strictly permitting `https:`, `http:`, and `mailto:`, while blocking `javascript:`, `data:`, `vbscript:`, and relative schemes.

## 7. Privacy, Network & Permissions Conformance

### 7.1. Privacy Invariant
- **Local-First Architecture:** 100% of user data (notes, tasks, bookmarks, settings, layouts, goals) resides in the user's local browser IndexedDB (`NookSpaceDB`).
- **Zero Telemetry:** No Google Analytics, no Mixpanel, no Sentry, no tracking pixels, no telemetry beacons.
- **Zero Cloud Accounts:** No mandatory authentication, no user registration, no server synchronization.

### 7.2. Outbound Network Traffic Audit
- **Network Call Scope:** Exactly **one** external network service is integrated: Google S2 Favicon API (`https://www.google.com/s2/favicons?domain={domain}&sz=64`).
- **Privacy Safeguards:**
  - The URL passed to the API contains **only the domain hostname** (e.g. `github.com`).
  - Full URLs, paths, query parameters, search tokens, titles, and notes are never transmitted.
  - If network connectivity is lost or blocked, an offline SVG monogram fallback is immediately rendered.

### 7.3. Permission Minimization Audit
Manifest permissions strictly comply with the Principle of Least Privilege:
- `"storage"`: Used solely for reading and writing fast synchronous anti-flash theme preferences and cross-tab event tokens.
- `"alarms"`: Used for background Pomodoro interval scheduling.
- `"tabs"`: Used for cross-browser tab opening and switching in Quick Links.
- **Omitted Permissions:** No `<all_urls>`, no `*://*/*`, no `webRequest`, no `history`, no `cookies`.
