## 4. PRIVACY & DATA HANDLING AUDIT

### 4.1. Local Storage Architecture
NookSpace stores 100% of user data locally inside the client's browser sandbox:
- **Primary Database (`NookSpaceDB`):** 17 user tables storing notes, bookmarks, tasks, sessions, goals, layouts, and workspace settings.
- **Recovery Database (`NookSpaceRecoveryDB`):** Transient snapshots for restore rollback and migration journaling.
- **Browser Extension Storage (`storage.local`):** Reactive event broadcasting across open New Tab pages.

### 4.2. External Network Audit
- **Application Backend:** 0 (Zero servers).
- **User Accounts / Cloud Database:** 0 (Zero authentication).
- **Telemetry / Analytics:** 0 (Zero tracking).
- **Google S2 Favicon Service:**
  - Endpoint: `https://www.google.com/s2/favicons?domain={domain}&sz=64`
  - Transmits **only the extracted hostname domain** (e.g. `github.com`).
  - Never transmits paths, query parameters, titles, notes, or user IDs.
  - Falls back immediately to an offline SVG `Globe` icon upon failure or offline mode.
- Full details documented in [`docs/release/privacy/NETWORK_DISCLOSURE.md`](file:///d:/NookSpace/docs/release/privacy/NETWORK_DISCLOSURE.md).
