Milestone 10.3 establishes rigorous, empirical proof that NookSpace preserves 100% of user data and behaves consistently across real browser runtime environments and multi-tab lifecycles. ## F. BACKUP, RESTORE, MERGE & MIGRATION VERIFICATION

1. **Export $\to$ Validate:**
   - Universal JSON backup engine exports all 17 active tables into a single self-describing, versioned JSON payload.
   - Web Crypto SHA-256 integrity checksum with recursive canonical key sorting guarantees deterministic payload hashing.
   - Input validator rejects corrupted checksums (`CHECKSUM_MISMATCH`), unknown formats, and files exceeding the 100 MB hard limit.
2. **Restore Engine:**
   - Preflight inspection acquires exclusive lock `'current_restore_lock'` in `NookSpaceRecoveryDB.locks`.
   - Pre-restore snapshot stored in isolated database before destructive operations begin.
   - Clears and replaces all 17 tables inside a single atomic Dexie read-write transaction in foreign-key dependency order.
   - Post-restore verification validates table counts and default workspace presence before releasing lock.
3. **Merge Import:**
   - Non-destructive selective import of 8 data scopes.
   - Normalized content fingerprinting prevents duplicate bookmarks and notes.
   - Deep ID remapping safely assigns new UUIDs to incoming records while recursively rewriting all foreign references (`workspaceId`, `collectionId`, `groupId`, `noteId`, `bookmarkId`).
   - Stale plan guard rejects import if database state modified during user dialog review.
4. **Data Migration:**
   - Idempotent topological engine resolves dependency graphs (Kahn's algorithm).
   - Handles schema migrations (v1 $\to$ v4), entity transformations (legacy todos, legacy quick notes), and foreign-key healing.
   - Interrupted migrations transition from `running` to `failed` (`MIGRATION_INTERRUPTED`) via `startupRecoveryCoordinator.ts`.

## K. PRIVACY & SECURITY AUDIT

1. **Local-First Verification:** 100% of user data (notes, todos, bookmarks, settings, layouts, focus sessions) resides strictly inside client IndexedDB (`NookSpaceDB`).
2. **Zero Telemetry & Tracking:** Zero analytics scripts, zero external tracking pixels, zero phone-home pings, zero mandatory cloud accounts.
3. **Network Activity Audit:** Core application features operate completely offline. The only network request that can be emitted is optional external favicon fetching via Google S2 favicon service (`https://www.google.com/s2/favicons?domain=...`) in `SmartBookmarksWidget`, which includes an offline SVG monogram fallback on network error or offline mode.
4. **Content Security Policy (CSP):**
   - Chromium MV3: Prohibits inline scripts, remote code execution, and `eval()`.
   - Firefox MV2: `script-src 'self'`. All code compiled into local extension chunks. Zero inline scripts.
5. **Protocol Sanitation:** Strict URL validation (`validateBookmarkUrl`) rejects `javascript:`, `data:`, `vbscript:`, and arbitrary URI handlers before persistence.
6. **Markdown Safety:** Note rendering uses AST token generation without raw HTML evaluation (`dangerouslySetInnerHTML`), eliminating XSS vectors.
